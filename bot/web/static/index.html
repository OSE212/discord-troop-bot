Troop Command — Setup Guide & Commands

Everything you need to set up the bot for your alliance, manage permissions, and run battle formations.

Invite Bot to Discord
STEP 1

1. Invite & Grant Roles

Click the Invite Bot button above to add Troop Command to your Discord server. Then create or assign two roles to your leadership:

  • Troop Admin: Grants full management (edit players, import CSVs, change rules). Anyone with Discord Administrator or Manage Server automatically qualifies.
  • Troop Calculator: Allows alliance leaders (R4/R5) to trigger /calculate formations.
STEP 2

2. Player Registration

Members register their troop and hero progression in Discord:

/register

Opens an interactive modal to enter In-Game Name, March Limit, FC levels (Infantry, Lancers, Marksman), and Helios counts.

/update

Used whenever an account upgrades (e.g. unlocking new FC tier, obtaining more Helios, or leveling heroes).

STEP 3

3. Optimize Battle Formations

When planning a Rally or Garrison:

/calculate

Prompts for Attack/Defence, Rally/Garrison, troop ratios, and total capacity. Calculates the optimal troop composition and identifies the Top 4 Joiners to maximize active skills.

STEP 4

4. Bulk Import (Google Survey)

Gather member data in bulk with Google Forms:

Roster ➔ Import CSV

Use our 1-click Google Apps Script generator to auto-create the survey in Google Drive, collect responses in Google Sheets, export to CSV, and import!

Discord Slash Commands Reference

Command Permissions Description
/register All Members Guided 2-step modal to register your In-Game Name, March Limit, and Troop stats.
/update All Members Update your existing registered stats, FC levels, Helios counts, or hero progression.
/profile All Members Display your personal registered troop card and hero levels.
/calculate Troop Calculator Calculate an optimized Rally or Garrison formation with troop allocation breakdown and Top 4 Joiners.
/rules Troop Admin View current optimizer weights (Helios multiplier, FC level priority order).

⚡ Google Survey Generator (1-Click)

Generate an interactive Google Form in 5 seconds to collect member march limits, FC levels, Helios, and hero stars.

1
Copy the Apps Script: Click the Copy Script button below.
2
Open Google Apps Script: Go to script.google.com (or in any Google Sheet: Extensions ➔ Apps Script).
3
Paste & Run: Paste the code into the editor, click Save, then click Run.
4
Export & Import: Share the generated form link with your alliance. In the connected Google Sheet, download as CSV and upload it here via Import CSV!
Google Apps Script (createAllianceTroopForm.gs) 
function createAllianceTroopForm() {
  var form = FormApp.create('Alliance Troop & Hero Registration');
  form.setDescription('Please register your account stats, Fire Crystal (FC) troop levels, Helios counts, and key hero stars.\nThis data is used by alliance leadership to calculate optimal battle formations.');

  // 1. Account Info
  form.addTextItem().setTitle('In-Game Name').setRequired(true);
  form.addTextItem().setTitle('Game ID').setHelpText('In-game numeric Player ID').setRequired(false);
  form.addTextItem().setTitle('March Limit').setHelpText('e.g. 165000 or 165k').setRequired(true);
  form.addTextItem().setTitle('Discord Username').setHelpText('e.g. username#1234').setRequired(false);

  // 2. Troop FC Levels
  var fcChoices = ['FC 10','FC 9','FC 8','FC 7','FC 6','FC 5','FC 4','FC 3','FC 2','FC 1','Level 30','Level 29','Level 28','Level 27','Level 26','Level 25'];
  var heliosChoices = ['No', 'Yes', 'Yes - 50k', 'Yes - 100k', 'Yes - 150k', 'Yes - 200k+'];

  // 3. Infantry
  form.addPageBreakItem().setTitle('🛡️ Infantry Specialization');
  form.addListItem().setTitle('Infantry FC').setChoiceValues(fcChoices).setRequired(true);
  form.addListItem().setTitle('Infantry Helios').setChoiceValues(heliosChoices).setRequired(true);

  // 4. Lancers
  form.addPageBreakItem().setTitle('🐎 Lancers / Cavalry Specialization');
  form.addListItem().setTitle('Lancers FC').setChoiceValues(fcChoices).setRequired(true);
  form.addListItem().setTitle('Lancers Helios').setChoiceValues(heliosChoices).setRequired(true);

  // 5. Marksman
  form.addPageBreakItem().setTitle('🏹 Marksman / Archers Specialization');
  form.addListItem().setTitle('Marksman FC').setChoiceValues(fcChoices).setRequired(true);
  form.addListItem().setTitle('Marksman Helios').setChoiceValues(heliosChoices).setRequired(true);

  // 6. Joiner Heroes
  form.addPageBreakItem().setTitle('⭐ Key Joiner Heroes');
  var heroLevels = ['Not Owned', '1 Star', '2 Stars', '3 Stars', '4 Stars', '5 Stars (Max)'];
  var keyHeroes = ['Jessie', 'Patrick', 'Jasser', 'Seoyoon', 'Sergey', 'Ling Xue', 'Ahmose'];
  for (var i = 0; i < keyHeroes.length; i++) {
    form.addListItem().setTitle(keyHeroes[i]).setChoiceValues(heroLevels).setRequired(false);
  }

  Logger.log('Form created: ' + form.getEditUrl());
  Logger.log('Share Link for Members: ' + form.getPublishedUrl());
}
